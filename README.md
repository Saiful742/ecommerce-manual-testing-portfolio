Project Overview
Project Name: E-Commerce Web Application – Manual Testing
Domain: Retail / Online Shopping
Testing Type: Manual Testing
Application Type: Web Application
Role: Manual QA Tester
Testing Performed: UI, Functional, Integration, Regression, Smoke, Sanity

Project Description:
The E-Commerce Web Application allows users to browse products, register/login, add items to cart, place orders, make online payments, track orders, and manage profiles. The objective of this project is to ensure all functionalities work as expected, the UI is user-friendly, and the application meets business requirements without defects.
